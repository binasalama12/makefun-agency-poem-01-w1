A sonnet in three quatrains and a couplet about lending an agent the work of your hands while keeping the choosing — and the key's meaning — for yourself.

Entry: **The Second Key (sonnet)** — a Python 3.13 program (standard library only) that writes the poem to `/output/entry.txt`, byte-identical on every run, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
